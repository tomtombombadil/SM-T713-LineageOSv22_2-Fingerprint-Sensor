First public release. Makes the home-button fingerprint sensor work on the **Samsung Galaxy Tab S2 8.0 SM-T713 (`gts28vewifi`)** with **retiredtab's LineageOS 22.2 (Android 15)**, with SELinux enforcing: fingerprint lock-screen unlock, plus fingerprint login in apps.

**Please read the full step-by-step guide in the [README](https://github.com/tomtombombadil/SM-T713-LineageOSv22_2-Fingerprint-Sensor#readme) before installing.**

## ⚠️ BEFORE UPDATING LINEAGEOS — FROM RETIREDTAB OR ANYONE ELSE — DELETE ALL FINGERPRINTS AND SET THE SCREEN LOCK TO "NONE". OTHERWISE YOU WILL MOST LIKELY BE LOCKED OUT AND HAVE TO ERASE THE TABLET. ⚠️

The same applies before uninstalling this package or flashing any other ROM.

## Downloads — you need all four

| File | Install with |
|---|---|
| `T713-fingerprint-v4-install.zip` | TWRP |
| `T713-fingerprint-v4-uninstall.zip` | TWRP (keep it for uninstalling) |
| `T713-fingerprint-selinux-rules-magisk.zip` | Magisk → Modules (**required**, install **before** the TWRP zip) |
| `T713-recovery-permissive-magisk.zip` | Magisk → Modules (safety net — install, then switch **off**) |

The TWRP zips are named "v4" because they were the fourth test build; they are what this v1.0 release contains.

## Tested with

- SM-T713, retiredtab `lineage-22.2-20260909-UNOFFICIAL-gts28vewifi`
- TWRP 3.6.2_9-0 (gts28vewifi)
- Magisk v31.1
